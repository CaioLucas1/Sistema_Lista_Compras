# Sistema Lista de Compras
O projeto apresenta um planejamento da lista ordenada, que também é demonstrada pela ordem alfabética, facilitando a leitura e a localização das informações pelos usuários. Esse recurso tem como objetivo organizar e apresentar informações de forma clara, acessível e visualmente compreensível para o usuário, contribuindo para uma navegação mais intuitiva e eficiente.
